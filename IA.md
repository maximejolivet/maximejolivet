| Repo | Description |
| --- | --- |
| [anthropics/claude-code](https://github.com/anthropics/claude-code) | Agentic coding tool that lives in your terminal, understands your codebase and handles routine tasks, code explanations and git workflows through natural language |

| [drona23/claude-token-efficient](https://github.com/drona23/claude-token-efficient) | A single `CLAUDE.md` file, with no code changes, that stops Claude from padding answers (openers, restated questions, unsolicited suggestions, over-engineering) to reduce output tokens. Benchmarked on Claude only; keep the file short since it adds input tokens on every turn |
| [21st-dev/magic-mcp](https://github.com/21st-dev/magic-mcp) | Search 10,000+ React/Tailwind components, generate new UI with AI, and publish your own — right from your editor (Claude Code, Cursor, Windsurf) |
