# 🤖 GitHub repos on AI

A selection of repositories I've starred around AI, coding agents and LLMs.

## 🤖 Coding agents & Claude Code

| Repo | Description |
| --- | --- |
| [anthropics/claude-code](https://github.com/anthropics/claude-code) | Agentic coding tool that lives in your terminal, understands your codebase and handles routine tasks, code explanations and git workflows through natural language |
| [affaan-m/ECC](https://github.com/affaan-m/ECC) | Agent harness performance optimization system: skills, instincts, memory, security and research-first development for Claude Code, Codex, Opencode, Cursor and more |
| [agentskills/agentskills](https://github.com/agentskills/agentskills) | Specification and documentation for Agent Skills, a simple open format for giving agents new capabilities and expertise ([agentskills.io](https://agentskills.io)) |
| [rtk-ai/rtk](https://github.com/rtk-ai/rtk) | CLI proxy that reduces LLM token consumption by 60-90% on common dev commands; single Rust binary, zero dependencies |
| [drona23/claude-token-efficient](https://github.com/drona23/claude-token-efficient) | A single `CLAUDE.md` file, with no code changes, that stops Claude from padding answers (openers, restated questions, unsolicited suggestions, over-engineering) to reduce output tokens. Benchmarked on Claude only; keep the file short since it adds input tokens on every turn |

## 📚 Official & reference skills

| Repo | Description |
| --- | --- |
| [obra/superpowers](https://github.com/obra/superpowers) | Complete software development methodology for coding agents, built on composable skills: clarifies the spec first, then plans and runs subagent-driven development with red/green TDD, YAGNI and DRY. Works with Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot CLI, OpenCode and more |
| [anthropics/skills](https://github.com/anthropics/skills) | Anthropic's implementation of skills for Claude: folders of instructions, scripts and resources that Claude loads dynamically for specialized tasks. Examples range from creative work and web app testing to MCP server generation and enterprise workflows, plus the document creation/editing skills (docx, pptx, xlsx, pdf) |
